ENTRADAS ENFOCADAS

Este código HTML y CSS crea un formulario con dos campos de texto para capturar el nombre y apellido del usuario. Mediante CSS se personaliza la apariencia de los campos, definiendo su tamaño, espaciado y borde. Además, utiliza la pseudoclase :focus para cambiar el color de fondo del campo cuando el usuario hace clic sobre él o lo selecciona, mejorando la interacción visual del formulario.
